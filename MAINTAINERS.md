# Maintainers

The [sdk-java-maintainers team](https://github.com/orgs/agentnameservice/teams/sdk-java-maintainers)
maintains this repository. The [sdk-java-reviewers team](https://github.com/orgs/agentnameservice/teams/sdk-java-reviewers)
provides reviews. Current membership and GitHub access are recorded in
[the organization team configuration](https://github.com/agentnameservice/.github/blob/main/peribolos.yml).
Propose membership changes there through a reviewed pull request.
